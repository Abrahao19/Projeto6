# Grupo6

Git Club-Plataforma de colaboração entre desenvolvedores

Sobre o projeto

 O Git Club é uma plataforma web para desenvolvedores compartilharem projetos, trocarem conhecimento e formarem equipes de trabalho, com integração ao GitHub.

 Funcionalidades para usuários
 
 Criar conta e entrar na conta
 Seguir e ser seguido por outros usuários
 Enviar mensagens diretas (DM)
 Perfil profissional com biografia, habilidades e tecnologias
 Portfólio com projetos em destaque
 Conectar a conta ao GitHub
 Pesquisar usuários e tecnologias
 Sistema de reputação e conquistas

 Funcionalidades para projetos
 
 As funcionalidades para projetos, até agora são,
Publicar projetos públicos ou privados,
Curtir, comentar e favoritar projetos,
Adicionar colaboradores,
Buscar projetos por tecnologia,
Issues e Pull Requests,
Histórico de commits e releases,
README e estatísticas do projeto.

Sistema de Reputação

Ganha pontos quem:

Ajuda outras pessoas,
Tem uma resposta aceita,
Cria um projeto,
Recebe curtidas e favoritos,
Contribui em projetos,
Corrige uma issue.

Perde pontos quem:

 Faz spam em publicações (-5 pontos),
Publica conteúdo repetido sem propósito (-3 pontos),
Tem uma resposta removida por violar regras (-5 pontos),
Comete ofensa ou assédio (-10 pontos),
Copia projeto sem dar crédito (-10 pontos),
Comete fraude de contribuição (-20 pontos),
Reincide em infrações (-50 pontos).


Tecnologias utilizadas

Front-end:HTML, CSS, JavaScript

Back-end:PHP

Banco de dados:MySQL

Ferramentas e APIs:Git, GitHub, GitHub REST API, XAMPP, Visual Studio Code
